# پنل OpenVPN — قابل دیپلوی کامل روی Railway

## نکته فنی مهم (لطفاً قبل از هر چیز بخوانید)
Railway به هیچ کانتینری دسترسی به دستگاه TUN و `CAP_NET_ADMIN` نمی‌دهد. این یعنی **هیچ پنلی — نه این، نه هیچ پنل دیگری — نمی‌تواند خودِ تونل OpenVPN را داخل Railway اجرا کند.** این محدودیت خودِ پلتفرم Railway است.

این پنل چه‌کار می‌کند:
- ✅ کاملاً روی Railway اجرا می‌شود: مدیریت کاربران، ساخت خودکار CA/گواهی/کلید هر کاربر با openssl، ساخت فایل `.ovpn` آماده، ربات تلگرام، بکاپ.
- ✅ یک اسکریپت نصب خودکار سرور (`install-openvpn-server.sh`) می‌سازد که وقتی یک VPS واقعی گرفتید، با یک دستور (`sudo bash install-openvpn-server.sh`) سرور OpenVPN را رویش نصب می‌کند — با همان CA پنل، پس کاربرهایی که همین حالا ساخته‌اید بدون نیاز به ساخت دوباره وصل می‌شوند.
- ❌ تا وقتی این اسکریپت را روی یک VPS اجرا نکنید، فایل‌های `.ovpn` ساخته‌شده وصل نمی‌شوند — چون سروری که به آن‌ها گوش بدهد وجود ندارد.

## دیپلوی روی Railway
1. New Project → Deploy from GitHub repo.
2. **Variables**:

| متغیر | مقدار |
|---|---|
| `SESSION_SECRET` | رشته تصادفی طولانی |
| `ADMIN_USERNAME` | یوزر ادمین دلخواه |
| `ADMIN_PASSWORD` | رمز قوی و اختصاصی |
| `DB_PATH` | `/data/panel.db` |

3. یک **Volume** با Mount Path `/data` اضافه کن (وگرنه با هر دیپلوی، کاربرها و گواهی‌ها پاک می‌شوند).
4. مطمئن شو Public Networking/Domain برای سرویس فعال است (برای اینکه خودِ پنل در دسترس باشد؛ این ربطی به سرور OpenVPN ندارد).
5. Deploy.

## استفاده از پنل
1. با یوزر/پس ادمین وارد شو.
2. «+ ساخت کاربر»: نام، سقف حجم (اطلاعاتی) و مدت اعتبار را وارد کن → فایل `.ovpn` ساخته و دانلود می‌شود.
3. تا اینجا فایل ساخته شده ولی وصل نمی‌شود (طبق توضیح بالا).

## راه‌اندازی سرور واقعی (وقتی VPS گرفتید)
1. یک VPS ارزان با روت بگیر (هر ارائه‌دهنده‌ای — چند دلار در ماه کافی است) و Ubuntu 22/24 رویش نصب کن.
2. از پنل، «دانلود install-openvpn-server.sh» را بزن.
3. فایل را به VPS آپلود کن (مثلاً با `scp`) و اجرا کن:
   ```bash
   sudo bash install-openvpn-server.sh
   ```
4. در پنل، «تنظیمات سرور» → IP همان VPS، پورت و پروتکل را ثبت کن.
5. کاربرهایی که قبلاً ساخته بودی را دوباره دانلود کن (چون آدرس سرور داخل فایل نوشته می‌شود) و برای کاربر بفرست.
6. از این پس، هر کاربر جدیدی که در پنل بسازی همان آدرس را دارد و مستقیم کار می‌کند.

## راه‌اندازی ربات تلگرام (اختیاری)
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده → `/newbot` → توکن را کپی کن.
2. توکن را در پنل، بخش «ربات تلگرام»، ذخیره کن.
3. به ربات خودت `/start` بفرست تا آیدی چت را بگیری، آن را هم در پنل ذخیره کن.
4. دستورات: `/status`, `/list`, `/add نام حجم روز`, `/on شناسه`, `/off شناسه`, `/del شناسه`.
